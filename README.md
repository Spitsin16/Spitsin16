## Selected Projects

### [Vokiri](https://github.com/Spitsin16/Vokiri)

An English-learning application focused on vocabulary management and personalized learning.

- Implemented JWT authentication and user management.
- Built bilingual dictionary lookup using FreeDict.
- Developed personal vocabulary management and custom translations.
- Structured backend logic using a service-layer approach.
- Added Alembic migrations and automated testing.
- Developing spaced repetition and AI-assisted reading features.

**Stack:** Python, FastAPI, SQLAlchemy, Alembic, SQLite, Pydantic, JWT, pytest.

### [Kvitto Payments API](https://github.com/Spitsin16/test-task-kvitto)

A payment API for an online education platform.

- Implemented tariff retrieval and payment creation.
- Designed support for installment payments and promo codes.
- Added idempotency keys for payment requests.
- Implemented payment status handling through webhooks.
- Used integer monetary amounts to avoid floating-point errors.

**Stack:** Python, FastAPI, REST API, pytest.

### [Football Agency Backend](https://github.com/Spitsin16/football-agency-backend)

A backend application for managing football clubs, players, agents, and match statistics.

- Designed a relational PostgreSQL database.
- Modeled player-club history and match participation.
- Built REST API endpoints using FastAPI.
- Implemented SQL queries with JOIN, GROUP BY, and aggregation.

**Stack:** Python, FastAPI, PostgreSQL, SQLAlchemy, SQL.
